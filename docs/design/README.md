# Brollam Partners: Design Exploration

This directory records the design exploration that preceded and guided the build: the reference landscape, the art direction and asset system, the typography system, the motion language, and the CMS collection model that the whole experience is assembled from.

| Document | Contents |
| --- | --- |
| [Digital neighborhood](digital-neighborhood.md) | Reference sites studied, what was borrowed, what was rejected |
| [Art direction and asset map](art-direction.md) | Moodboard rationale, visual language rules, every shipped asset with alt text |
| [Typography system](typography.md) | Typeface choices, scale, pairing rules, usage contract |
| [Motion language](motion.md) | Timing and easing vocabulary, choreography rules, accessibility gates |
| [CMS collection model](cms-model.md) | Collections, fields, states, and the integrity rules enforced in the schema |

Everything in these documents describes decisions that are live in the repository. Where a decision lives in code, the file path is referenced directly.
